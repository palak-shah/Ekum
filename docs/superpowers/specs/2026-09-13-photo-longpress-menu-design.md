## Behaviour

| Gesture | Photo message | Other messages |
|---------|---------------|----------------|
| Tap collage | PhotoViewer | (unchanged) |
| Long-press | Open Ekum actions menu | Enter Select (forward) when allowed |
| Chevron | Same menu | Same menu |
| Long-press while selecting | Toggle select | Toggle select |
