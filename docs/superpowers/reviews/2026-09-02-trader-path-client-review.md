# Middle shop — three looks, two switches

**Example:** Kavita = supplier · Ravi = trader · Meena = buyer

**First order** for this pair: order is **with Ravi**. Kavita and Meena **do not** see each other. **No group.** Nothing extra on the share/order screen.

---

## Three looks (what they see)

| Look | Order is with | They see each other? | Where they talk |
|------|---------------|----------------------|-----------------|
| **With me** *(first time)* | Ravi | No | Two private chats (Meena–Ravi, Ravi–Kavita) |
| **With the mill** | Kavita | No | Meena–Kavita private. Ravi sees the order on his list. |
| **Group** | Ravi **or** Kavita (Ravi picks) | Yes | **One** chat: Kavita + Ravi + Meena. Order updates sit here. |

Group looks the same either way. **Who the order is with** is still Me or the mill — that is not the same thing as the group.

---

## How Ravi changes it (two lines, not four choices)

Not on the everyday Place / Send screen. Same two lines on **More** (that sheet), the **order page**, and **Your paths**:

1. **This order is with** → **Me** / **{Kavita’s shop name}**
2. **Kavita and Meena can see each other** → Off / On  
   - On: *One group chat. Order updates go there.*  
   - Off: *They only talk to you, not to each other.*

**Your paths** (You / Settings): search + list — supplier, buyer, order with, see each other. Tap a row to change. We **remember** this pair until Ravi changes it.

Group name = three shop names. Same group next time (including if staff change).
