# Collections

## Purpose

Collections are **named albums** that group designs. Own albums use the seller’s library; **curated collections** may also reference other companies’ designs (see [Saved & Curate collection](./saved.md)). They are not a second photo store — membership is always designs (products).

## Who uses it

Sellers building collections for shop / Explore. Buyers view published albums via Explore or company profile (`/collections/:id`) when the album is **inside its live window**.

## User flows

### Create & edit (seller)

1. **＋** (bottom nav) opens a **Collection** sheet: **Create new collection** → **New collection**; **Update existing collection** → You **Collections** (tap a collection → viewer; add/remove designs on the album; **Edit collection details** for name/rate/tags/units). Buy-only ＋ still opens Orders; no upload cap → why-line toast. New collection: bottom nav hidden; sticky one row **Create & Publish** (primary) · **Save in Draft** (secondary). Empty and after members: **Add from existing designs** · **Add photos** side by side (dashed foam tiles — not a floating sheet). **Designs** = library picker (no camera permission). **Photos** = ContinuousCamera (stream ready before shell; **Gallery** on chrome — OS picker, including Android; must not retake via camera). Each new photo becomes a **new design**; more angles of the same design = tap tile → **Add photos**. After members: grid (cap **9** + **Load more**) + the same in-tile **Designs** · **Photos**. Camera Done = **Add N designs**. New photos get a session **SKU** (`EK-…`) as the design name until they type one (not the file name). Identity on the page, in order: **Collection name** (placeholder *Name this collection*); **Rate** with **One rate** / **A range** pill switch (live ₹ caption when filled — no On request on this page); Description; **Product description** typeaheads (**Item tags** and **Quality / work tags** always multi-select; **Size** one optional pick) from official drill-down (`GET /v1/catalog/taxonomy`, filtered by what they deal in; same tree is upserted as official CatalogTags on API boot) — custom allowed at every slot; official picks can stack. Collection tags are the union of filled slots (appended onto members, no duplicates). **Who can see this?** is a chevron on the page (Settings prefilled). Pack **Rate** / range is saved on the collection (Edit reloads it). Create/edit shows **Rate per** + unit select (default **pc**; pack order syncs dispatch unit, else order unit). Changing it updates designs with no rate or still on the previous pack rate; a design with a different rate is left alone. Album facts rate: **pack rate** from add/edit first; if unset, **min–max from priced designs** (blanks ignored). Owner always sees the band on their album; **on request** hides it from other users. Quiet row **Apply this info to all designs** stamps units / MOQ / notes only — never overwrites a design rate (selected-row chrome when on; remembered per device). Tags union from the pack either way. **Order and dispatch** (optional, collapsed accordion on create/edit — open to set; values stay prefilled when collapsed): Order taken in · 1 set contains · Dispatch unit · Minimum order · preview `10 sets (= 40 pcs)`. Platform usual is **set** until Catalog defaults; first official Item tag can suggest dispatch unit. **Create & Publish** publishes from the dock — if Who is incomplete, that row opens. **Save in Draft** leaves. No collection cover. After create → You → Collections. Edit keeps identity + Same-for-all expandable **below the design photos** (same order as New collection: images first). Visibility / Publish for a saved collection still uses the sheet.
2. On edit **and** own album viewer opened to **manage** (You / ＋ → Collections / own shop — `location.state.packManage`): bottom nav hidden; sticky dock one row **Designs** · **Photos** · **Replace**. Own album opened from **Explore** (or chat / Saved / share): **no** manage dock — app nav stays; same membership actions live under header **⋯**. Owner **⋯** always (manage or Explore): **Share** · **Who has access** · **Add from existing designs** · **Add photos** · **Replace entire collection** · **Edit collection details**. Dock short labels; menu uses full labels. All membership actions run on the album — never hop to Edit for Add/Replace. **Edit** sticky dock **Update collection** only (filled primary — pack details; no member grid). Membership stays on the album (not on Edit). **Replace** (dock or ⋯) opens a sheet to choose **Add from existing designs** or **Add photos**, then that picker. Waits until a non-empty new set is saved. Header on Edit is **⋯** only (not Select — membership select stays on the album; not a ghost **Update** next to Open). **Add designs** (library) lists only designs **not already in this album** — already-in members stay out of the way (remove via **Select** on the album). **Replace** library still shows the full library. If every library design is already a member (Add only), the sheet says so quietly. **New designs** (Photos or library) go **on top** of the album; existing keep their order. **Select** / long-press → tools row **Select all** · **Clear** (no sticky float); tiles use the same little shrink + half-size filled check as Explore (gap is page surface, not teal; × hide while selecting); when the manage dock is on, selecting turns it into **Add to cart** · **Share** · **Delete** icons · **Remove from this collection** button. Cart = published checked designs into the trade cart (toast; exit Selecting). Remove = leave this collection only. Delete on **your** designs = remove from the library when it is only in this collection; if it sits in other collections, confirm **Delete from all collections** or **Only this collection**. Delete on a **mill design you curated** = drop it from **this collection** (your curation) — it does not delete the mill’s library. Own shop name card is **hidden** on your collections (visitors use subtitle **from {shop}**). Publish / Visibility / Hide stay under Edit header **⋯**. Identity fields + expandables stay on Edit, **under the design grid** (images first, like Add designs). **Open** is Edit **⋯** → buyer album.
3. Lifecycle: **Draft → Published → Archived**. Path is **Your paths** / TradeLane — not on collection fields. Schedule (**When**) deferred — collections go live on publish. Who = **Followers** / **Selected** (buyer groups or pick companies). **Everyone** removed. Multiple groups = member union; rates/relist strictest wins.
4. My Catalog → Collections **and** Designs: the list is **published** (no Published chip). **Draft / Archived / Bookmark** are the Find **filter menu** (square beside search, like Orders / Explore). Collection member designs live under **Designs** as **Published** (In your collections, no solo Explore tiles) as soon as they join the collection. **Save in Draft** on New collection is the quiet exception. **Curated mill designs are not extra Designs rows** — only collections you own show on Collections; mill identity is **From {shop}** on that collection. **Grid** tile: name · then **From {shop}** / **Yours and {shop}** / **From N shops** as its own semibold line when members are foreign · then muted **N designs** · optional **shared with N** (Selected audience company count when live; omit for Followers / Everyone / empty Selected — never show **Published** or a date on the listing). Collage shows up to 4 **design** thumbs (first photo each, never a collection cover) with **`+N`** leftover designs on the 4th cell when `productCount > 4` (`+1` for 5 designs). **Feed** on **Explore** still has the shop row. **You** and **shop catalog** Feed omit it (name is already on the page / under shell **My collections**). Mosaic → name → owner mill caption (when foreign members) → same **N designs** · **shared with N** rule (no listing date). Up to 3 collection **tags** stay muted. No Curated chip. Collections Find matches collection name, tags, member SKU/notes, and **original mill shop names**. Tap album → viewer; **Edit** on viewer returns to editor. **Select** (header or **long-press** a tile) → multi-publish / **Hide · draft** (published) / archive / restore. On the **owner’s** curated viewer: **From {shop}** under the collection title (semibold) plus **From {shop}** on foreign design tiles; buyers still see only the collection owner. In-collection Search also matches mill shop names.

### Album viewer chrome (uniform action language)

Header is one tight row — title · ⋯. Visitor scan stack: title → pack details (**read more** clamp, expands to rate · description body (no Rate/Description labels) · labeled **Size** · **Item tags** · **Quality tags**; Size omitted when empty) → **Find · Select · Feed/Grid** (tools above the lot) → designs → **Order** only when this collection has picks. Find stays a toggle (not a permanent field); no tag/rate Filters strip on the album.

Publish / Hide / Archive stay on editor **⋯** (same bottom sheet chrome). |

**Header subtitle:** `N designs` · for visitors `from {shop}` (link to shop) — no rate band in the header. Below: one pack-details block (default ~2–3 lines with quiet **read more** on the last clamped line — not its own row; rate and description as plain body, labeled **Size** · **Item tags** · **Quality tags**; omit empty; Size only when set). No flat categories dump or **About this collection** chevron on the album. **Feed and Grid** tiles show the design **name** only (no rate / On request chip on the thumb; multi-photo **+N** when needed) — no SKU/code and no **From {mill}** under the tile (curated mill credit stays on the pack source line when shown). Tap a design → photos sheet with labeled **Rate** · **Size** · **Description** · **Item tags** · **Quality tags** (omit empty / On request rate), optional MOQ, Bookmark · Select. On **your own** designs, the sheet also has **Edit design** → Edit design page.

Default layout is the trader’s last **Feed / Grid** choice (device-local); **Ekum default is Feed** when never set. Same preference is shared with Saved and My designs. Library home is **You**; `/catalog` opens You. Also Home **My designs** when selling — no Catalog bottom tab. **＋** chooses create vs You Collections; Add designs is on You. Nav ＋ does not open Add designs.

### View (buyer)

1. Open album from Explore, company profile, or chat card → `/collections/:id` only when status is published **and** now is within `startsAt`/`endsAt`.
2. Scan designs: header → pack details (**read more**) → tools (**Find** · **Select** · Feed/Grid) → designs. **Find** (not a permanent field) filters **this collection’s designs** by tag, rate (incl. ₹ / commas /mtr and prices inside a band), name, notes, SKU, shop, or unit; close clears. **Select** (or long-press) → this-collection shortlist; float **Select all** / **Clear** for this album’s designs. Whole collection order = **Select all** then **Order**. Subset = pick then **Order**. A pile from Explore/other collections does **not** show counts or Order lines here. **Curated collection (visitor):** **Order goes to {collection shop} · You chat with them. They send the mill lots on** only when Your paths ticket for this buyer × those mills is **me** (I handle). Ticket **mill** (Direct) hides that line. Place is still from-pack with the collection owner. `/collections/new` opens create (`/catalog/collections/new`). **1 design** when the collection has one. Photo tap **toggles** pick while selecting; the **name always opens** the design sheet (more photos). In the sheet, tap the **main photo** → shared **PhotoViewer**.
3. Respect connection / audience / **Granted on request** for full detail. Gated collections: **Ask to see this collection** (Allow/Deny in owner chat) — look through only; not Connect; not Curate unlock.

## Business rules

| Rule | Detail |
|------|--------|
| Membership | Many-to-many; any owned non-archived design may be added |
| Publish album | Requires ≥1 design; publishes the **collection** on Explore. Own draft members become **Published** for Order / Share / Curate **inside** the collection, but do **not** get `postedToMarketAt` (no separate Explore design tiles — avoids flooding buyers when a collection has many designs). Publish a design from My designs later to put it alone on Explore — unless a **live collection already on that feed** still includes it (then the collection stays and the solo tile is omitted). |
| Relist lock | `allowForward` snapshot. Uncheck **Buyers can add these designs to their collections** → they cannot **Curate** it. **Forward** the card is still free. |
| Download lock | `allowDownload` on collection + member designs. Uncheck **Buyers can download these designs** → buyers must not export photos (buyer export UI may follow). Default from Settings; else off. |
| Shop defaults | Habitual Who / rates / curate / download / order-and-dispatch live in **Settings**; New collection inherits until tweaked. |
| Curated member ended | Unpublished members are **not** on Explore, shop, or the album viewer (count is live designs only). Editor still lists them. **Hide from Explore** is the only collection unpublish. Adding your own designs/photos to a collection **publishes** them with the collection’s who / rates (no Explore design tiles). **Replace** waits until the new set is saved. New photos are library designs and stay published with a live collection. |
| Share to chat | **Universal Share** (paper-plane; sheet hugs content, scrolls when long) posts cards into a **chat** (not broadcast), with optional message note. Allowed when you own it, it was already in a chat you’re in, or it’s discoverable on Explore (e.g. Followers collection you are **allowed** to follow). |
| 48h share link | Universal Share: quieter native **Share** icon beside primary **Send** (not a second filled CTA). One door per chat unit: each album, one leftover design, or **2+ leftover designs** (kind `designs` — collage of designs, not a Collection). Mix (album + design) keeps the control — one tap, N URLs in the body (not one fake collection token). If Share or clipboard cannot run, the sheet keeps the URLs to select and copy. WhatsApp preview: **seller · collection/design(s)**, blurred collage teaser (`/share-links/:token/og-image`). Guest `/s/:token` is public. **Everyone** (live): look-only design collage + name + designs; **Open on Ekum** → join → collection, design, or virtual set `/designs/set?ids=…` (per-design access). Closed: collage + name + **Request access** (OG may still tease thumbs). Already on Ekum: collection/design jump to live viewer; **designs** → `/designs/set` (Feed/Grid first; tap a design for PhotoViewer; rate / photos / min / tags / **From {shop}** per design). Expires 48h. Not a guest shop. |
| Selected groups | `audienceGroupIds` remembered for Visibility restore; visibility still gated by `audienceCompanyIds` (union of members) |
| Multi-group rules | One collection = one rates/forward snapshot; if selected groups disagree → strictest (on_request / no-forward) |
| Live window | `startsAt` null = live on publish; `endsAt` null = Evergreen; past `endsAt` → Hide → draft (job + read guards) |
| Seller status line | List + Edit show current truth (phase · who · when) — not a chip pile or activity log |
| Unique names | Non-archived collections per company must have unique names (case-insensitive). On New collection a taken name opens a sheet: **Add to that collection** (append designs) or **I’ll use another name** — not a red error. Restore blocked if name is taken. |
| Explore resurface | `exploreActivityAt` bumps on first publish / republish after hide — not on audience-only tweaks while already published |
| Hide / archive | Hide → draft (edit quietly); Archive ends the season; **Restore** (⋯ or dock) → draft again |
| Quick add photos | Creates draft **Product** rows (name from filename), not orphan photos. Capture matches Add designs (ContinuousCamera on phone). |
| Own manage dock | Owner viewer: Designs · Photos · Replace (on album). Edit: Update only. Select Delete / Remove. Replace sheet asks Designs or Photos, then opens that picker; waits until a non-empty new set is saved (cancel / pick nothing keeps the collection). Delete sole-pack → product delete; multi-pack → confirm all vs this collection only. |
| Owner name card | Hidden on own collections; visitors use subtitle **from {shop}** (no full shop card on the album). |
| Designs vs collections | Tabs stay separate — see [concepts](./00-concepts.md) |

## Edge cases / empty states

- Collections empty: “Albums of designs from your library.”
- Publish disabled until at least one design is in the album.
- Pre-start published albums: sellers see **Starts…**; buyers do not see them.
