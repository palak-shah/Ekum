# Collections

## Purpose

Collections are **named albums** that group designs. `Collection.kind` is **general** (one per company, identity is the flag never the name), **regular**, or **catalog**. Own albums use the seller’s library; **curated collections** may also reference other companies’ designs (see [Saved & Curate collection](./saved.md)). They are not a second photo store — membership is always designs (products). General Collection membership is **computed** (no join rows): own non-deleted designs with no qualifying regular/catalog join, including drafts. Catalogs stamp pack rate onto own designs on add; orders always snapshot `Product.rate`.

## Who uses it

Sellers building collections for shop / Explore. Buyers view published albums via Explore or company profile (`/collections/:id`) when the album is **inside its live window**.

## User flows

### Create & edit (seller)

1. **＋** (bottom nav) opens a **Collection** sheet: **Create new collection** → **New collection**; **Update existing collection** → You **Collections** (tap a **published** collection → viewer; tap a **draft** → editor; add/remove designs on the album; **Edit collection details** for name/rate/tags/units — General Collection is name and description only, no apply-all or Order and dispatch). Buy-only ＋ still opens Orders; no upload cap → why-line toast. New collection: bottom nav hidden; sticky one row **Create & Publish** (primary) · **Save in Draft** (secondary) on the shared page CTA dock (`BottomTradeDock`). **Save in Draft** works with the name, category, and designs still empty; it **stays on the editor** (`/catalog/collections/:id`) so they can keep adding name / designs / Publish. You list shows **Untitled** until they name it. Own draft / leftover ready / deleted tiles from You open the **editor** (not an empty album). **Owner** album (regular, catalog, General Collection) lists non-archived members; draft designs get a quiet **Draft** chip. **Buyers** still see live published designs only. **Create & Publish** still needs a name, a category, and at least one design. Empty: **Add from existing designs** · **Add photos** side by side (dashed tiles, same field fill as name / Description — not a floating sheet). After members: compact **N designs · tap to change** strip (peek thumbs); tap expands the grid (cap **9** + **Load more**) + the same compact **Designs** · **Photos** tiles. **Designs** = library picker (no camera permission; selected tiles use the same little shrink + 18px accent check as Explore / album — top-right on the thumb, not a green ✓ or teal frame). **Photos** = ContinuousCamera (stream ready before shell; **Gallery** on chrome — OS picker, including Android; must not retake via camera). Each new photo becomes a **new design**; more angles of the same design = tap tile → **Add photos**. Camera Done = **Add N designs**. New photos get a session **SKU** (`EK-…`) as the design name until they type one (not the file name). Identity on the page, in order: **Collection name** (required, red *); **Description** (optional free-text blurb, one kit row that grows while typing, no placeholder); **Product details** (quiet section): **Category** (always on the form — full catalog, not only Settings deal-in; if they deal in exactly one, that one is pre-selected; tap opens a sheet of tappable rows, not the OS dropdown; empty is muted with no **Pick category…**; Rate per options follow the selected category) → **Rate** with **One rate** / **A range** (₹ prefix; One rate placeholder **Rate**; A range labeled **From** / **To** — no formatted ₹ echo under the field; no On request on this page) → **Item tags**, **Quality / work tags**, and **Size tags** only after Category is chosen (always multi-select; focus opens suggestions without typing — used tags first, then official, cap 8; chips stay above the field and in the visual viewport so the keyboard does not cover them or the list; scroll the list does not pick; tap to add; list stays after a pick so they can add another; Escape / tap outside / empty Enter / keyboard Done closes it). Sheet footer is **Done** only — no **Use same as all designs** (that label fights pack **Apply this info to all designs**; matching others is Apply on the pack, or type the same fields). Official tags come from official drill-down (`GET /v1/catalog/taxonomy` for the selected category; same tree is upserted as official CatalogTags on API boot) — custom allowed at every slot; official picks can stack. Other empty fields have no placeholders (no “Optional” / “Start typing”). Kit placeholders (Rate, 1 set contains, search, design name) are **14px roman muted** — same as Category, not italic — and **hide on focus**. Kit control height (40px); Description starts one row. Collection tags are the union of filled slots. They **append onto own-company member designs** (no duplicates, cap 20) on create, **Edit collection details**, and album **Add** — mill designs are left alone. Removing a pack tag later does not strip it from a design. The member sheet shows the union; **Done** saves that sheet list as-is so they can drop a pack tag on one design. **Who can see this?** is a chevron on the page (Settings prefilled). Pack **Rate** / range is saved on the collection (Edit reloads it). If Category no longer offers the current unit (e.g. leftover **pc** on fabric), Rate per switches to the Category **primary** (typically **mtr**) so the field is valid. Create snaps Rate per to that primary until they pick another; **Jobwork** stays **mtr**, not pc. **Update collection** writes Rate per and **1 set contains** on the collection, then stamps own member designs (the editor reloads pack units from the collection). **Apply this info to all designs** overwrites every own member’s rate (including designs that already had a rupee). Pack rupee without Apply still only overwrites designs that follow the pack rate. After stamp, How many / tickets use the **design** Rate per. Explore / album pack cards may still show collection details ₹ when set. Failed Update toasts. Kit **Button** `loading` (shared Spinner) on **Update collection** / **Create & Publish** / **Save in Draft** so a double-tap cannot fire twice. Changing Category or Rate per is unsaved work (leave prompt). Empty library picker: **Add photos** (collection camera), not a solo-design hop. Leaving the camera hard-stops the stream (privacy LED off). Album / Explore pack ₹: **collection details Rate / Rate per when set** (even if designs kept their own rupee); else **min–max from priced designs** (blanks ignored; mixed rate units omit only when the pack has no rate). Unpriced leftover /pc must not hide a priced follower’s /mtr. How many uses each **design** Rate per. Owner always sees the band on their album; **on request** hides it from other users. Quiet row **Apply this info to all designs** on a **regular** collection (label in the chip; how-to on the shared circle **i**: **overwrites member rates**; **tags add on**; stamps units / pack size / MOQ / notes when on; remembered per device). **Catalog** always stamps — the row is hidden. **New catalog** (`?kind=catalog`) is Catalog name* + exclusive why-block + **Order as whole / Pick and choose** (no treat-as checkbox). Catalog picker source is General Collection leftovers + new photos only. Regular picker includes designs already in other regular packs. Catalog-member **Update this design** is photos, name, notes (catalog owns category/rates/dispatch). Adding an own design to a catalog copies catalog rate/units onto that design. `setProducts` does **not** auto-publish drafts — only explicit **Publish** promotes own draft members. Empty or 0 in 1 set contains sends piecesPerPack null (clears leftover size) Tags union from the pack either way. **Order and dispatch** (optional, collapsed accordion on create/edit — open to set; values stay prefilled when collapsed): Order taken in · 1 set contains (empty: no placeholder — blank + Rate per unit suffix only, e.g. **mtr**; typed **0** or blank is not given and clears stored pack size; typed number shows **n mtr/mtrs** beside the number when Rate per is mtr, not leftover **pc**; contents in **Rate per** unit; order unit **dozen** autofills **12** when empty, editable) · Dispatch unit · Minimum order · preview `10 sets (= 40 pcs)`. Platform usual: **order + dispatch = set**, **rate / contains = pc** (accordion summary e.g. `set · 12 pcs`, never `12 sets`). Catalog defaults can override; first official Item tag can suggest units **only when order/dispatch are still empty**. **Changing master category does not rewrite** Order taken in / 1 set contains / Dispatch. Official item/quality/size tags that the new category does not offer may drop; **custom tags stay** (no confirm wipe). **Create & Publish** publishes from the dock — if Who is incomplete, that row opens. **Save in Draft** stays on the editor (draft editor keeps Add designs / photos — published edit is still pack details only). Create & Publish a collection leaves to You → Collections; Create & Publish a catalog leaves to You → Catalogs (published). Opening Who, Order and dispatch, album-change, or Show details scrolls the opened block into view above the dock. No collection cover. Edit keeps identity + Same-for-all expandable **below the design photos** (same order as New collection: images first). Visibility / Publish for a saved collection still uses the sheet.

### View (buyer)

1. Open album from Explore, company profile, or chat card → `/collections/:id` only when status is published **and** now is within `startsAt`/`endsAt`.
2. Scan designs: header → pack details (tags · price, **more...** on that line for the description) → tools (**Find** · **Select** · Feed/Grid) → designs. **Find** (not a permanent field) filters **this collection’s designs** by tag, rate (incl. ₹ / commas /mtr and prices inside a band), name, notes, SKU, shop, or unit; close clears. Typed letters are marked in the design name, shop line, and meta. **Select** (or long-press) → this-collection shortlist; float **Select all** / **Clear** for this album’s designs. Whole collection order = **Select all** then **Order**. Subset = pick then **Order**. A pile from Explore/other collections does **not** show counts or Order lines here. **Curated collection (visitor):** **Order goes to {collection shop} · You chat with them. They send the mill lots on** only when Your paths ticket for this buyer × those mills is **me** (I handle). Ticket **mill** (Direct) hides that line. Place is still from-pack with the collection owner. `/collections/new` opens create (`/catalog/collections/new`). **1 design** when the collection has one. Photo tap **toggles** pick while selecting; the **name always opens** the design sheet (swipe all photos in-sheet; tap a photo → shared **PhotoViewer**).
3. Respect connection / audience / **Granted on request** for full detail. Gated collections: **Ask to see this collection** (Allow/Deny in owner chat) — look through only; not Connect; not Curate unlock. Quiet link **Request access on their shop** is the shop Follow ask, not this collection Ask.

## Business rules

| Rule | Detail |
|------|--------|
| Membership | Regular packs: many-to-many; any owned non-deleted design not already in an own catalog. Catalogs: own designs exclusive (`catalogCollectionId`); curated mill members are allowed. Removing an own design from its only regular collection or catalog returns it to **General Collection** (catalog also clears the exclusive stamp). Album Remove uses full owner membership so unpublished members are not wiped. General Collection membership is computed — not writable. `setProducts` does not change Product.status. **Add to collection / catalog** on You Designs and General Collection. Regular album: **Add to other collections**. Catalog-exclusive designs: **Move to catalog / collection** (leaves the current catalog, including into another catalog — the source join is not “already exclusive”). Mixed leftover + exclusive omits the door. You Designs select ⋯ always when something is selected (Add or Move · Repost · Hide · Delete last). Owned album select ⋯: Bookmark · **Draft** · **Publish** · Add (General Collection too; catalog album is Bookmark · Draft · Publish · Move when every pick is exclusive · Remove · Delete). Lists **published and draft** packs (Deleted hidden; **Draft** chip). Find + Select all / Clear use the same album chrome as You. Packs this design already belongs to pin first under **Already in** (every membership, including its exclusive catalog — not togglable; Remove stays on the album). Collections are multi-select. Catalogs show for leftover Add and for **Move** of exclusive designs; at most one catalog; picking a catalog cannot also pick collections. Rows use the You list thumb; headings Already in, then Collections, then Catalogs. |
| Publish album | Requires ≥1 design; publishes the **collection** on Explore. Own draft members become **Published** for Order / Share / Curate **inside** the collection, but do **not** get `postedToMarketAt` (no separate Explore design tiles — avoids flooding buyers when a collection has many designs). Publish a design from My designs later to put it alone on Explore — unless a **live collection already on that feed** still includes it (then the collection stays and the solo tile is omitted). |
| Relist lock | `allowForward` snapshot. Uncheck **Buyers can add these designs to their collections** → they cannot **Curate** it. **Forward** the card is still free. |
| Download lock | `allowDownload` on collection + member designs. Uncheck **Buyers can download these designs** → buyers must not export photos (buyer export UI may follow). Default from Settings; else off. |
| Shop defaults | Habitual Who / rates / curate / download / order-and-dispatch live in **Settings**; New collection inherits until tweaked. |
| Curated member ended | Unpublished members are **not** on Explore, shop, or a **buyer** album (visitor count is live designs only). The **owner** album lists draft members with a **Draft** chip. Editor still lists them. **Hide from Explore** (copy **Draft**) is the only collection unpublish. Adding designs does **not** auto-publish them — only **Publish** promotes own draft members (no Explore design tiles). After publish, the owner can **Draft** selected designs; those stay on the owner album and leave the buyer album. A published design in a draft pack stays on You → Designs and on other live albums. **Replace** waits until the new set is saved. |
| Share to chat | **Universal Share** (paper-plane; sheet hugs content, scrolls when long) posts cards into a **chat** (not broadcast), with optional message note. Allowed when you own it, it was already in a chat you’re in, or it’s discoverable on Explore (e.g. Followers collection you are **allowed** to follow). |
| 48h share link | Universal Share: quieter native **Share** icon beside primary **Send** (not a second filled CTA). One door per chat unit: each album, one leftover design, or **2+ leftover designs** (kind `designs` — collage of designs, not a Collection). Mix (album + design) keeps the control — one tap, N URLs in the body (not one fake collection token). If Share or clipboard cannot run, the sheet keeps the URLs to select and copy. WhatsApp preview: **seller · collection/design(s)**, blurred collage teaser (`/share-links/:token/og-image`). Guest `/s/:token` is public. Guest design collage stays **closed** (Request access) — Everyone is no longer open catalog; legacy rows behave as Followers. Already on Ekum: collection/design jump to live viewer when audience allows; **designs** → `/designs/set` (Feed/Grid first; tap a design for PhotoViewer; rate / photos / min / tags / **From {shop}** per design). Expires 48h. Not a guest shop. |
| Selected groups | `audienceGroupIds` remembered for Visibility restore; visibility still gated by `audienceCompanyIds` (union of members) |
| Multi-group rules | One collection = one rates/forward snapshot; if selected groups disagree → strictest (on_request / no-forward) |
| Live window | `startsAt` null = live on publish; `endsAt` null = Evergreen; past `endsAt` → Hide → draft (job + read guards) |
| Seller status line | List + Edit show current truth (phase · who · when) — not a chip pile or activity log |
| Unique names | Non-archived collections per company must have unique names (case-insensitive). On New collection a taken name opens a sheet: **Add to that collection** (append designs) or **I’ll use another name** — not a red error. |
| Explore resurface | `exploreActivityAt` bumps on first publish / republish after hide — not on audience-only tweaks while already published |
| Hide / Delete | Hide → **Draft** (edit quietly). **Delete** = soft `archived` (irreversible; no Restore). Deleted filter lists them. General Collection cannot be drafted or deleted. |
| Quick add photos | Creates draft **Product** rows (name from filename), not orphan photos. Capture matches Add designs (ContinuousCamera on phone). |
| Own manage dock | Owner viewer: one **Update collection** button. It opens **Add designs** · **Add photos** · **Replace entire collection**. Edit: Update only. Select Delete / Remove. Replace sheet asks Designs or Photos, then opens that picker; waits until a non-empty new set is saved (cancel / pick nothing keeps the collection). Delete sole-pack → product delete; multi-pack → confirm all vs this collection only. |
| Owner name card | Hidden on own collections; visitors use subtitle **from {shop}** only — never **N designs** / collection inventory counts for other shops (no full shop card on the album). |
| Designs vs collections | Tabs stay separate — Collections · Catalogs · Designs. See [concepts](./00-concepts.md) |

Rename + description allowed; no tags/category/rate/Apply this info to all designs/Order and dispatch/Draft/Delete/setProducts. Album identity is the note only — no pack Rate or tags. Album has no pack journey line. Designs keep Rate per / tags / Order and dispatch on the design editor and opened design. Hidden from Explore and shop shelf. |
| Catalog | `kind=catalog` + `orderMode` (whole \| pick) from **New catalog** (not a treat-as checkbox). Own designs exclusive; picker = General Collection leftovers; **Move** relocates exclusive designs. Exclusive why-block uses the warning wash (same as order notes) so it cannot be skimmed. Stamp catalog rate onto own members on add. Orders follow whole / pick (mill send-as-bunch and trader-curated mill IDs). **Order as whole:** no Choose designs; DesignSheet / album / cart Order opens How many as **catalog name + one qty** (read-only members).
