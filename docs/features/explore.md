# Explore & search

## Purpose

Discovery surface for posts (collections and designs), businesses, and federated search. Ranking is **opportunity / interest**, not engagement vanity metrics. Network nodes are **companies**, not individual people. Publishers are opaque **businesses** (no trader/seller labels).

## Who uses it

Buyers, sellers, and dual-role companies. Explore is not limited to “seller catalog only” — curated collections from dual-network companies publish here too.

## User flows

1. Open **Explore** (`/explore`) — **Stories** rail, then shelves / filters. Feed chrome is Chats-tight (36px shop avatar, small Stories, `gap-2.5` between search / Stories / posts). Collection mosaic + collection name use the same page gutter as the header (`px-4`) — inset from the screen, not shoved under the shop name. Under the mosaic: Instagram icon row — left **Repost · Message · Share**, trailing **Bookmark** (icon-only; **always show all four**; gray out when not allowed — own post, not Trading / `allowForward` false, or while Selecting; **Message** = quick enquire bar (avatar + pill + send, like a short comment) for that collection/design — Send cards + note, **stay on Explore**) — then **title** (no muted activity / **N designs** under the title) · teal **rate band** when honest (collection only if publish rates are **visible** and members share one unit; design when rate is present — never invent On request as a price) · muted **From {mill}** when a curated collection opts in (**Show supplier name**) · muted **category tags** · description when present (album-style clamp: **read more** on the last line · **Show less**; newlines preserved — not an **About this collection** chevron). Relative time sits **top-right beside the shop name** (header trailing; with Follow / Request when those show). **Repost** opens an on-page sheet (not Your selection): collection name · Publish Who (followers / selected groups · companies) · rates · buyers can add to collections · download · **Show supplier name** (default off) · primary **Repost** · quiet **Repost + share a link · 48 hours**. Multi-pick piles still use Your selection **Repost**. No View collection / Share button pair under the card; open stays tap mosaic / title. **Own** published collections/designs appear on Buying (Stories **You** first when you have activity). Shop header on own posts says **You** — no Request catalog access.
2. **Filter square** — root: **Change View** · **Select Category** · **Select City** · (dual only) **Explore Buyers** / **Explore Suppliers**. Content type: **View Items By** — All Feeds / Collections Only / Designs Only / Businesses Only (`?show=`). Category and city are multi-select (starts-with search, Confirm). **Clear** on a Category or City row clears that facet only. No All / Buying / Selling chips.
3. Tap a Story → filter posts from that business (`?story=`); Clear or Open shop if no posts in shelf.
4. **Buying** = posts (and Stories). **Selling** = **Buyers for you** only. Selling never shows My Catalog. Suggested-supplier shelf is not on the buying feed — directory is filter square → **Businesses Only**.
5. Filter by one or more categories / cities (OR within a facet, AND together). Collection and design **tags** (`categories` labels) match Explore search `q` the same way as product categories — **case-insensitive** exact label match (so `bedsheet` finds a collection tagged `Bedsheet`).
6. Request catalog access (ask); open album or design detail (`/explore/products/:id`, `/collections/:id`). Explore chrome is **search + Filter square + Select** (shop’s Select pill, not a Saved or Selection square — Saved is **You → Saved**; Selection is the floater when the pile is non-empty). **Select** is hidden while searching, on Selling, and on Businesses Only. Design page is tight: full-bleed square photo (tap → PhotoViewer, swipe more photos there), one company row, rate / min / notes — no second “View business” link and no filmstrip of small cards. Sticky **Curate · Ask for rates · Order** is **visitors only** on a visible design (same as collection `visitor`; portaled dock, tab bar hidden while it is up) — owner never sees that dock, including when Selling or Trading is on.
   - **Start pick with Select** (same as shop / Saved). Then tap the mosaic or photo to add. Long-press still works as a shortcut. **Album:** mosaic → select album. **Design:** photo → select design. Both can stay selected together (types preserved — albums stay albums). Same traveling **Selection** as Saved, company shop, curated albums, and My designs/collections. Selected media uses a shared look app-wide: a clear shrink so pick is obvious, plus a filled teal check with a light ring; the gap is page surface (never a teal frame on the photo). Shop / library **cards** may use an accent **card** border when selected. Unselected tiles stay full color (never greyed). Long-press uses a non-link press target so iOS Safari does **not** show Open / Open in New Tab. Idle short tap on the photo / mosaic opens the album or design. While **Selecting**, the photo / mosaic **toggles** pick; the **name always opens** (collection or design — more photos). Design cards show the **first photo only** (extra photos on the design page). Long-press select must **stick** (Android: ghost click after entering select mode must not toggle the item off).
   - When the traveling **staging** pile is non-empty on **Explore** / design set / design or collection while Selecting: **bottom nav hides** and a sticky dock shows **Add to cart · Message · Share** (icons) + **Order** (filled, right). No “N in selection · View” row. No staging count badge on **Add to cart** (count stays on Select all float; cart count stays on header). **Add to cart** merges staging into the **cart**, clears checks / Selecting, toast. **Order** merges into cart then opens **Cart** (`/selection`) with the order flow. **Message** opens a quick enquire bar on staging — **stays on the page**; staging **stays** (unlike Share). Multi-shop disables Message. Explore header **Cart** (bag + badge) opens the cart. Hidden on Home, Chats, Orders, You, Settings, Network, **company shop**, `/selection`, and whenever Ask / Order owns the band. Dock **Share** clears staging after a successful send.
   - **Cart** dock: **Repost** (Trading on) · **Bookmark** · **Share** (icons) + **Order** (filled, right), then **Clear cart**. Staging ≠ cart — Select only stages until dock **Add to cart** / **Order**. Repost reads the **cart** pile (not empty staging). **Company shop:** Message · Share · Order only when **this** seller has picks (unchanged this slice). Cart empties on Clear or after a successful cart action. After **Bookmark**, app opens **Saved**. After **Order**, app opens the **first successful ticket** in **chat**. **Cart** hides the bottom nav.
   - **Share** / **Bookmark** keep original types (collection cards / Saved collection refs + design cards / Saved design refs). They do **not** expand an album into its designs. **Share** (paper-plane) opens **Universal Share** (bottom sheet that hugs content height, scrolls when the list exceeds the viewport): pick **one or many** companies (one search filters connections; quiet **Find on Ekum** link after 2+ characters — same as New chat — not a second empty Find box; Clear), **Publish-style buyer-group chips** when groups exist, quiet **Create group** text, optional message, primary **Send** into unique chats — not Broadcast compose. Quieter native share icon (iOS upload) mints the 48h link.
   - **Order** needs design lines. If any collection is selected, a resolve sheet asks per album **All designs** or **Choose designs** (open album to pick). **Continue** expands All into How many each. A locked collection (no design list) opens that album instead of a “not listed yet” error. Empty collection: **{name} has no designs.** Expanding All **dedupes** by product id. A collection is never an order line.
   - **Curate** uses **selected designs only**. Selected collections are not auto-expanded for Curate.
   - Unavailable picks stay on Your selection (faded + **No longer available**) — never silently dropped. Explore never lists a collection with no live design. **Access only** (no inventory): a design stays available while the viewer can still open it — market post, connection, chat share, **or** still a member of a published live album whose designs are visible to them. Surviving logout does not fade rows when access is unchanged. **Curate-check** (`Can't see this now`) is **not** a list reason — it only skips those ids when saving a collection. Seller lock on the list stays **Can't put in a collection** + Ask.
   - **Request catalog access** on post card header when you are not allowed, not pending, and not connected (asks — not instant). Hidden when pending, already Has access, connected, own post, or select mode. Shop header is **name + GST tick** and **city · categories** (not Connected / GST chip). Relative posted time sits beside the shop name (header trailing), not under the title. Shop **Message** is the first-chat path.
   - Collection page header subtitle is **N designs · ₹low–₹high /unit** when loaded members share one sold-as unit and at least one rate (space before the unit). Mixed units, all On request, or no member list → count only.
   - Design cards (search tile, collection tile, collection photo sheet) always show the shop name. Owner viewing a curated foreign member still uses **From {shop}**. Buyers see mill **From {shop}** credit only when the collection’s Publish toggle **Show supplier name** is on (`showSourceShops`; default off — otherwise design lines use the collection shop name).
   - Locked (`allowForward: false`): **Can’t put in a collection** under the title (before select). **Share** / **Forward** still include them. **Curate** skips locked designs **and locked collections** (no Pick designs into a collection-locked album). **Order** / **Bookmark** still work.
   - **Select** sits after Filter (same `SelectModeControls` as album / shop; **`showSelectAll={false}`**). Tap **Select** → **N selected** · **Clear** (Select hides; no Select all on the mixed feed). **Clear** deselects and exits. While Selecting, shell **Back** beside the **Explore** title goes to **Home** (same as You → Home). Selecting does not lock the feed: tap the name to open.
7. Search — federated company / collection / design; feed stays until the user types (UX rule). Idle bar and focused field share **Search supplier, collection or design** — no GST (GST is profile / Find on Ekum). Category copy uses human labels (`Women's apparel`, never `womens_apparel`) on the feed relevance line, search chips, design tags, and shop tags.
8. From company cards → public profile → follow / request access / chat.

### Trade-side

User control is **Buying** or **Selling** only (`?side=`). Dual presence (I buy + I sell) defaults to **Buying**; last filter row is **Explore Buyers** (→ Selling) or **Explore Suppliers** (→ Buying). Buy-only / sell-only stay in that side; the row is hidden. Old `?side=all` is treated as Buying for dual (Buying for buy-only; Selling for sell-only).

| Side | Intent |
|------|--------|
| **Buying** | Ranked feed: **allowed follows first**, then **connected + your categories**, then **category matches**; **Received** collections by UTC day then business (directed audience or broadcast — not Everyone-market); Stories for allowed-follow / connected publishers who posted |
| **Selling** | **Buyers for you** — companies whose buy interests match what you sell. Not My Catalog. Requires sell categories on your profile. |

## Business rules

| Rule | Detail |
|------|--------|
| Visibility | Blocked companies never appear; audience (`everyone` / `connections` / `followers` / `selected`) enforced server-side |
| Designs on Explore | Published designs with `postedToMarketAt` (Publish sets both). On Explore home and the mixed feed, if that design is already a member of a **live collection in the same result**, hide the solo tile — the collection is the album. Solo Publish still shows when the design is not on a visible live collection. **Designs Only** still lists posted designs. |
| Collections on Explore | Published albums with activity / live-window rules — see [collections](./collections.md) |
| Follow | Ask; Buying side prioritizes **allowed** followed publishers’ posts. Pending never ranks as a follow. |
| Ranking (feed) | Interest / opportunity matching (`feed-rank`, `interest-match`) — not likes/viral scores. **Seen posts** sink within a tier until the post has newer activity (device-local for now; server sync later at scale). Landing paints the first posts from a light `/explore/feed` while `/explore/home?sections=feed` enriches Stories + ranked shelves. Explore home shows **12 posts** then **More posts** so discovery shelves are not buried; when the list is fully shown, a quiet **You've reached the end** footer. Mixed / collections / designs lists **virtual-scroll** only after **24** posts (the 12-post window + More posts stays real layout so caption height cannot leave a blank band above More posts). Cover images **easy-load** (src deferred until near viewport; first two cards eager). API `feed` / `collections` pull a **ranking window** (not the whole market) then page. |
| Stories | Company appears when viewer is an **allowed** follower or is connected and company has **published** to feed (own or curated). Rank by recent publish; hide rail when empty; not Instagram personal stories |
| Role opacity | No Trader / Seller badges on Stories or cards |
| Businesses directory | Filter square → **Businesses Only**. Not mixed into the buying post feed. |
| Businesses tab | Directory = **2-col grid** of company tiles (one cover). Companies with live Explore posts (not self, not blocked). Rank: **interest match first**, then **newest post activity** |
| Why-lines | Ranking may still use Connected / match internally. **On screen** the shop line is city · sell categories. GST is a tick by the name. |
| Curated collections | Publish curated collections (multi-supplier, within original seller forward/audience). Capability `relist`. See [saved](./saved.md) |

## Edge cases / empty states

- Cold start: **Find in Explore** / **Find on Ekum** from empty Chats and Share sheets → browse or look up businesses.
- **Share** (Selection / album / collection): paper-plane opens **Universal Share** (content-height sheet, scrolls past viewport) — multi-select connected companies (select · deselect · **Clear**); **one** search filters connections; quiet **Find on Ekum** link after 2+ characters (or immediately if no connections) — same New chat pattern; tap uses that text via `externalQuery` (no retype; no second idle Find field; no auto Ekum results while filtering); **buyer groups** as **Publish-style chips** (same lists), quiet **Create group** text (opens New buyer group; new group is selected). Selected-count line only after a pick. Optional message (composer without attach) rides the last card as enquire note. Primary **Send** uses **unique shops** (a company in two selected groups gets one chat). Posts collection cards and design cards (`POST /threads/direct` then messages) — not `POST /broadcasts`. Share is **not** an access check: published collection-only designs (no Explore tile) share like market posts. If the recipient cannot open a design, they **Ask the supplier** on that design — same as a gated collection. **2+ designs** post as **one** chat collage (`design_album`, **View designs →** → `/designs/set?ids=…` — not a Collection). That path opens the set page (tiles), not a photo strip. Tap a design for photos; from chat, **Quote** one design (same as photo Quote) so they can discuss it in the thread. Set page = Feed/Grid (same pill as Saved / shop) + **Select** (same as album). PhotoViewer only after a tap, in share order. While Selecting, **N selected · Select all · Clear** is a pill under Select (same as shop) — not a second header bar. Visible designs go on the traveling pile; Order / Ask rates on the floater. Locked tiles stay out. Each design shows available facts (rate, photos, min, tags, **From {business}**). Opens that chat when exactly one recipient. Quieter native **Share** icon beside Send mints **48h links** for every shareable unit (same cards as chat): each album, one leftover design, or **2+ leftover designs** as one `designs` door. A mix (e.g. 1 collection + 1 design) does **not** hide native share — one tap mints **N** links and puts every URL in the message body (optional composer note included). If Share or clipboard cannot run, the sheet keeps the URLs to select and copy. After join, each token opens that collection, design, or virtual set.
- Share with no connections yet → **Find on Ekum** link immediately + **Find in Explore** (not a dead end); 48h still offered whenever there is a shareable unit (solo, designs-only, or mix).
- Buying + no follows → empty followed shelf; still offer supplier discovery.
- Post feed: **Request catalog access** on the card when a stranger is not already Has access; hidden when pending, following, connected, own post, or select mode. Date under the post.
- Selected-audience posts hidden from non-selected viewers.
- Story with no posts in current shelves → Open shop → company profile.
- **Explore Buyers** with no sell categories → explain why the shelf is empty and link to **Business profile** (`/settings/profile?focus=sell`) — already editing; scrolls to **Categories you sell** and keeps that field highlighted until Update.
