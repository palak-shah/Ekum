# Chat

## Purpose

Company-to-company messaging for trade: text, photos, voice, and **cards** (collection / product / order / rate) with server-side **source masking**.

## Who uses it

Any company. Unconnected first messages land in the recipient’s **Requests** inbox.

## User flows

1. Open **Chats** → search. **＋** is a filled charcoal circle at the far top-right (after **⋯**). One sheet, sequential (no pills). **New chat** = pick **one** business (Find on Ekum is a **link** after 2+ characters in search, or **immediately** if there are no connections; tap shows shops **not already in Connections**; **Send invite** is OS share / copy — not a phone-book sync; empty query + no connections → name / mobile / GST field after tap). Multi-select and **New group / name** are gone from ＋ — groups are created only when a trader **reveals** on an order (trade-lane trio). Owner with staff: **Next** → **Add your team** (search when 10+ staff; **Select all** / **Clear**). Footer: **Open chat with {business}**. Success toast says **Chat started** / **Opened chat** / **Back in chat** from API `opened`. Header **Back** is the previous step (keeps picks); **Close** dismisses. Sheet height is fixed; steps stay mounted (hide, don’t remount). Inbox chips **All · Unread · Groups · Requests** (kit Chip: gray foam idle; **selected = chip-on tint**; lime count on Unread / Groups / Requests). Search is the same kit `SearchInput` as Orders / Explore. Inbox rows use **48px avatar** (group rows use the **group photo** when set; **no photo → people glyph**, not a letter) + comfortable vertical padding (`py-3`) — WhatsApp-comparable density; **hairline separators** and foam press (`listRowClass`), same as Home Followed and Settings stacks. 1:1 no-photo circles use a **pale wash + matching ink letter**. Inbox/headers show **business name** (or group title) only — no Team/Private labels. Rows stay flat (not cards), **two lines**: name on line one; object kind on the preview line as **12px title chip-on ink** (e.g. **Order**) then `text-meta` snippet — not a third line. Empty chips use kit `EmptyState` (15px title). Long-press a row keeps that row highlighted while the menu is open.
2. Open thread → **bottom nav hides** (WhatsApp; composer sits on the safe area). Send text / photo; **＋** attach: Design · Collection · **Camera** · **Photos** · **Photo order** (buying; 1:1 opens `/orders/new?seller=` with that shop selected and changeable) · Document · Order (share) · **Complaint** last (1:1 only — about this shop; not a group; does **not** tag the whole chat). Sheet: **What's wrong** * · **Add photos** (quiet link; camera / gallery, up to 9) · **More** · **Attach order** (quiet link → this shop's orders by design photo / name / date — not the hash; optional). Send posts a **complaint** card (subject, **More** text, thumbs from form photos **and** attached order designs, order line = design names + date — never `Order #`). Open / responded cards offer **Resolve** (either party); trader may also **Send to supplier**. Deep link `/chats/:id?complaint=1&order=` (from order ⋯) opens the same sheet against **this thread’s counterpart** with the order preselected. Trader **Send to supplier** creates a **new** complaint as the trader on the mill 1:1 (prefill; never as the buyer) — supplier defaults from the ticket’s designs / lot, with **Change** when more than one mill is released. Type **`@`** to mention a teammate on this chat or another business (pick above the composer); share design, collection, or order cards (**uniform layout** — kind icon + title · indented support · up to 3×60 thumbs · optional note · time hugging content · one footer rule; **kind badge** on chip-on; yours **chat-out** / theirs **chat-in** — no left rail; ~85% wrap, card min 262px; CTA names the kind); receive quote / order action cards from trade flows. Thread uses theme **chat** wallpaper. **Explore / album Share** can also drop a `collection_card` into a chosen chat (catalogue → chat). **Forward is free** for live published cards (blocked senders still cannot); opening the collection still checks view with the catalog owner. Share failures show **InlineNotice** in the sheet.
3. Inbox chips under search: **All · Unread · Groups · Requests** (kit FilterRail; count on Unread / unread Groups / Requests). Chip stays on that list after you open a chat and **Back** (or Chats tab). Deep link `/chats?inbox=requests` (Home Requests chip, old `/network/requests`). First-chat and connect-invite rows: **Approve** · **Ignore** in the thread. **Approve** on a first write activates the thread and creates **one mutual Connection**. See-new-collections asks in the same list: **Wants to see your new collections**, checkboxes **They can see my collections** (on by default) and **They can share my collections** (off), compact **Allow** · **Decline**. **Allow** applies checked grants (see → look; share → collection). **Decline** is silent deny. First-chat rows stay **Approve** · **Ignore**. **Block** is in More (swipe or long-press) — silent Network block, one tap. Swipe-left on a row: **More** · **Archive** (long-press menu stays). While **Selecting**, swipe **right** selects that row, swipe **left** deselects; tap still toggles. Idle swipe is unchanged. Completeness: `2026-10-27-pwa-select-swipe-completeness`. Group incoming bubbles show a shop thumb.
4. Pin chat. **Mute** on the thread **⋯** bottom sheet opens an in-sheet step (**8 hours / 1 week / Always**) with Back — same MoreActionsSheet chrome app-wide. Stay on, no pings — other shop does not see. **Unmute** is one tap. Last owner on the shop **1:1** cannot Leave — they mute. **Leave** (confirm sheet → off this chat; rejoin via `＋` → Open existing if still live). **1:1:** tap the **business name** → their shop (collections / designs). **Team on chat** is thread ⋯ (owners). **Media** is header **search + filter** (Photos / Documents / Designs / Collections) — not a separate page or ⋯ item. Groups: tap the **group name** → group page (header is **Back** only — name lives once under the photo; small **camera** to add a picture, **editable name**, **N businesses**, one-line or owner **Add a line** that expands a field there). Segments **Businesses · Media · Settings** (same bar as All Chats / Requests). **Businesses:** search + **＋** add connected shops. Below the shops: **Your team** (our people on this chat — never the other shops’ staff). Owners **Add** opens Team on chat; **×** takes staff off this chat (not owners). Search filters shops only (team hides while typing). A quiet **Share invite** in the ＋ sheet opens the phone’s share apps with a `/g/:token` link — not a second CTA next to Add. **Media:** Photos · Documents · Designs · Collections in this group. **Settings:** Mute · Pin · Team on chat (owners) · Leave · Remove group. Join if connected to a shop already on the group; else request to connect with the host. Not a people roster (other shops’ staff stay hidden). **Team on chat** (⋯ or Settings, owners only): **our** staff.
5. Unread badge on bottom nav (exact count, not 9+); mark read on open / header **⋯ → Mark all read**. **Scrolled up:** a small **down arrow** (40×40, above the composer, right) jumps to **latest** — WhatsApp-style; hidden at the end. Swipe left on an inbox row for **More · Archive** (on **⋯ → Archived**, the swipe says **Unarchive** and restores the chat). Header **⋯** is a **bottom sheet** (icon + text; same MoreActionsSheet as thread ⋯ / row long-press / shop ⋯ / account). **⋯ → Invite to connect** (one-tap share; not on ＋). **⋯ → Starred** (cross-chat starred messages as cards with **Unstar**) and **⋯ → Archived** (occasional lists, not peer tabs — bottom nav stays off; only the Chats tab keeps it) — open does not auto-unarchive (a new message still restores to All Chats). No **Select chats** / bulk delete dock — Clear / Delete stay on the row menu only. **Long-press** (or right-click) a row → bottom sheet **Pin · Mute · Mark as unread** (when already read) **· Archive / Unarchive · Clear chat · Delete chat** (1:1) or **Exit group** **· Block** last (1:1, Network, silent). Confirm Clear / Delete / Exit stays a sheet. Not copied from WhatsApp: Lock, Favourites, lists. A half-typed note stays on this device and shows **Draft: …** on the row. Archive hides the row (new message or **＋** Open existing or Unarchive brings it back to All Chats, not Requests). Clear empties history for us, row stays. Delete = clear + hide row. Confirm Clear and Delete. Cancel in the header. Requests stay **Approve / Ignore**; Block in More. ⋯ sits on the **Chats** title row — not beside the chips. Bell / You are Home only. Action disabled when nothing is unread. **Open thread like WhatsApp:** unread → land on first unread with **“N unread messages”** divider; no unread → newest + composer ready. Deep link `?message=` still wins. **Voice:** when the text box is empty, **hold mic** to record; **release** stages a preview (not auto-send). Too short / empty → toast, no send. Preview: play · **× delete** · Send. Slide left while holding cancels. Cap ~2 min. Bubble / quote note: compact play + progress + duration — no native `<audio>` chrome (Android).

## Edge cases / empty states

- Empty Chats → **Find businesses** → Explore (`Businesses Only` + search open).
- Empty **New** (no connections) → **Find on Ekum** link immediately, then name / mobile / GST if they tap with an empty search; **Find in Explore**. **Share** uses the same Find-as-link + `externalQuery` pattern (one search filters connections; Find button after 2+ characters). Other pickers (orders, Publish, …) still use the Find on Ekum **field**.
- Find on Ekum hit → **Request access** or **Message** (opens/starts a thread; not auto-connect). Already on the connection list → omitted from Find results (Add from the list above). Already in an **active chat** → **Message** only (no Request access; why-line **In chats**).
- Chats ＋ **Send invite** (after Find is opened) → connect link via OS share. Other pickers: invite only on a phone-like miss.
- Explore **Share** (Selection): **2+ designs** → one clubbed chat card (**View designs →** virtual set) and **48h link** kind `designs`; access stays per design. **1 collection + 1 design** → two chat cards and two 48h links (row stays).
